# Переход LectureVault к публичному сервису — 17 ноября 2026

Разрешён пользователем: настоящая регистрация, пустая библиотека, ручные Markdown-заметки без AI, необязательные личные подключения провайдеров в настройках. Studio + Quartz Editorial и готовые Quartz/Milkdown/CodeMirror сохраняются. Старые volumes, личные инструменты и CLI-профили не удаляются и не публикуются.

1. Регистрация/email/password, подтверждение email, вход/выход, восстановление/смена пароля, отзыв сессий. Argon2id, opaque HttpOnly/Secure cookies, строгий Origin/Host, постоянные rate limits. Проверки: случайный UUID пользователя, отсутствие демо-входа, изоляция данных, единоразовые истекающие ссылки, инвалидация сессий.
2. Реальные участники курса вместо alice/bob и автоматического общего курса. Приглашения owner/editor/viewer через email существующего подтверждённого пользователя; серверные ACL на каждом ресурсе. Новый аккаунт не получает ни курсов, ни заметок, ни чужих CLI credentials.
3. Настройки профиля/безопасности/подключений; обе ветки «Новый» доступны независимо от AI. Нет /demo, mock-переключателей и тестовых материалов в рабочем UI. Проверки: регистрация → ручная Note → Crepe/CodeMirror → сохранение/экспорт без провайдера.
4. Подключения провайдеров без жёсткого ограничения двумя аккаунтами. Пользователь делегировал выбор стандартного решения: официальный Codex device-code flow для удалённого сервера, Claude через собственный Anthropic API key с явной отдельной оплатой API. Loopback callback1455 удалён. Каждый CLI-процесс ограничен Linux Landlock собственным UUID-профилем; media — собственным каталогом задания. Ядро без ABI3 отказывает в запуске. Никаких общих профилей или передачи access/refresh tokens браузеру.
5. Отдельное production-окружение, HTTPS reverse proxy, строгая конфигурация домена/SMTP/secrets, отсутствие demo seeds, квоты на пользователя, backups/restore и проверка готовности. Публичная публикация только после локальной проверки и конкретной конфигурации домена, DNS/HTTPS/SMTP.
6. Unit/API/browser-приёмка в отдельном Compose project, скриншоты 1440/768/390, обновление спецификаций. Готовность публичного URL, доставка внешних email и вход провайдера не заявляются без фактической проверки.

Рабочая реализация и команды — README.md и SECURITY_AND_DOCKER.md. Production-overlay проверяется локальными TLS-сертификатами и SMTP AUTH+STARTTLS; настоящая публикация остаётся отдельным действием после настройки домена/SMTP.
