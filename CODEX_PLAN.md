# LectureVault — порядок выполнения и приёмки

Актуализировано 17 ноября 2026. Исходный согласованный план: [docs/plan-2026-11-10.md](docs/plan-2026-11-10.md). Дополнительные agent skills не использовать.

## Выполненный промежуточный этап

Quartz-эксперимент → Studio + Quartz Editorial → законченный frontend/mock/localStorage flow → адаптивность и polish. Сохраняются четыре оригинальных пользовательских референса. Не восстанавливать удалённые эксперименты, submission-архивы и handoff-файлы в исходное дерево.

## Разрешённый итоговый этап

Поручение «доделать задание полностью» разрешает backend/runner/editor. Пользователь 17 ноября разрешил реальный Codex вместо временно недоступного Claude, вход для обоих провайдеров и выбор модели/effort.

1. **Хранение и права:** FastAPI/SQLite WAL, два демопользователя, личные курсы и общий курс owner/editor/viewer, единая Note без обязательного source/job, revision conflict. Приёмка: данные переживают рестарт, прямые чужие API/asset/export недоступны, viewer не меняет документы.
2. **Очередь:** один worker, сохранение каждой стадии, cancel queued и retry failed только отправителем. Приёмка: несколько заданий, ошибка/повтор, восстановление INTERRUPTED после аварии, отсутствие дублей Note.
3. **Изолированный реальный путь:** ffmpeg/Whisper CPU → текст PDF → Codex/Claude CLI → Markdown. Приёмка: успешное собственное тестовое видео, результат содержит данные источника/PDF и не mock. Медиапарсеры не имеют CLI-профилей, внешней сети или доступа к API; профили провайдеров раздельны по пользователям, без медиа/vault. Все обработчики non-root. CUDA не включать без NVIDIA runtime; не менять host tools.
4. **Редактирование:** «Новый» с двумя сценариями, общий готовый Milkdown Crepe, CodeMirror, сохранение/переименование/экспорт. Приёмка: ручная пустая Note без job, оба типа Note проходят Markdown round-trip, 409 сохраняет черновик и предлагает явное разрешение конфликта.
5. **Подключение:** обычный браузерный OAuth Codex без device auth настройки, официальный Claude login, модель/effort только в форме генерации. Приёмка: отдельный профиль, токены не в UI/localStorage/logs/Git, подключение переживает рестарт. Claude без рабочей подписки не объявлять end-to-end проверенным.
6. **Финальная проверка:** unit/API/browser, production build, non-root/network проверки, реальные просмотренные снимки 1440/768/390, актуальные PRD/DESIGN/README. Browser-тесты создают отдельный Compose project/volumes и не чистят пользовательские данные.
7. **Сдача:** исходники и документы без секретов/медиа/зависимостей, реальный скриншот, видео до 60 секунд и краткий комментарий. Генерируемые материалы вне исходного дерева; не возвращать submission-мусор в Git. Push и публикация не выполняются автоматически.

## Границы

Без реального yt-dlp/произвольных URL, OCR, PPTX, realtime, SSO, графа, полного vault-import, дополнительных папок и публичного Quartz-export. PDF — текстовый слой, не распознавание изображений слайдов. Демо-авторизация только localhost. Ошибку real pipeline не подменять mock. Существующие konspekt, Obsidian, hse-notes, `.bashrc` и host CLI profiles не менять.

Приоритет оценки: завершённый сценарий, PRD/DESIGN, референсы, авторизация/сохранение, локальный запуск и честная демонстрация. Дополнительная ценность — реальный Whisper+CLI, PDF, права, очередь и конфликты. Количество функций и обещание 10/10 не заменяют официальную оценку.
