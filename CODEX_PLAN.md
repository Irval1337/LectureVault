# LectureVault — порядок выполнения (v2.2)

Нормативный план: [docs/plan-2026-11-10.md](docs/plan-2026-11-10.md). Дополнительные agent skills не использовать.

## До 11 ноября: UX и промежуточная сдача

1. Read-only аудит принят; план и первый прототип разрешены.
2. Сохранить план, синхронизировать PRD/DESIGN/USER_FLOW/handoff и промпты.
3. Эксперимент Quartz 5 до 60 минут: переиспользовать стабильные компоненты; при сложном мосте использовать готовый renderer и стили Quartz. Не переписывать Quartz.
4. React/Vite/TypeScript + Tailwind/shadcn: пустая библиотека → создать курс → видео/URL + необязательный PDF → пресет, объём, инструкции → mock-очередь → статья/TOC → .md скачивание. Сначала UX, затем инфраструктура.
5. localStorage сохраняет курсы, Markdown, задания, параметры, дерево и тему после refresh. Медиа не читаются и не сохраняются. Все видимые действия работают; mock отмечен.
6. Простой Compose web, проверки desktop 1440/mobile 390, реальные скриншоты, README и сценарий видео до минуты. Сверить PRD/DESIGN с реализацией.
7. Остановиться перед настоящим backend. Следующий этап требует отдельного согласования.

## До 19 ноября: после отдельного согласования

1. Аудит/план SECURITY_AND_DOCKER.md и prompts/06_docker_security.md. Non-root обработка, узкие mounts, без vault и прежних credentials.
2. FastAPI + SQLite, persist notes/jobs/assets, один worker, demo login двух пользователей, личные библиотеки и общий курс. Одна модель Note для ручного и сгенерированного Markdown; source/job необязательны, пустое тело допустимо. Серверные owner/editor/viewer и минимальный revision conflict (409).
3. Обязательный локальный файл: ffmpeg → Whisper → Claude CLI → Markdown. Новый адаптер внутри LectureVault без вызова konspekt/.bashrc. CUDA предпочтительна; CPU-резерв для короткого видео согласован.
4. Готовый общий Milkdown Crepe для всех Note. «Новый» → «Создать заметку» / «Сгенерировать конспект», также у `+` курса. Ручная пустая заметка без видео/job: создать → Crepe → сохранить/переименовать → открыть из дерева → reload → экспорт. Проверить пустое тело, формулы, таблицы, изображения и fenced code. Не писать собственный редактор; ручные заметки обязательны к 19 ноября, не для промежуточного прототипа.
5. PDF — приоритетное дополнение: безопасное извлечение/растеризация, текст слайдов и вложения. Затем отдельный CodeMirror.
6. URL/yt-dlp только после основного пути и подтверждённого SSRF-контроля; иначе отключён. PPTX и публичный Quartz-экспорт за пределами критического пути.
7. Проверки, воспроизводимый Compose, архив без секретов/storage/зависимостей, видео и рефлексия.

Нельзя подменять ошибку настоящей генерации mock-успехом. Нельзя менять старые konspekt, Obsidian, hse-notes и CLI-настройки, выполнять push или публичный деплой. Оценка зависит от официальных критериев, а не количества функций.
