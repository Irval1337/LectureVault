# LectureVault — выполнение и приёмка

Актуально17ноября2026. Текущая задача — подготовка настоящего сервиса к публикации, без учебных аккаунтов и seeds. Согласованный дизайн Studio + Quartz Editorial сохраняется. Исторический план: docs/plan-2026-11-10.md; актуальный: docs/production-plan.md.

1. **Аккаунты:** email/password Argon2id, подтверждение/восстановление, смена пароля, отзыв сессий, rate limits, protected cookies. Приёмка: пустой новый аккаунт, единоразовые истекающие ссылки, сброс отзывается во всех сессиях, нет списка чужих пользователей/демо-входа.
2. **Данные и права:** SQLite/volumes, реальные участники курса по email, owner/editor/viewer, единая Note, revision409, удаление своих данных. Приёмка: IDOR/asset/export запрещены, viewer не пишет, editor не меняет участников, удаление чужого курса запрещено; backup/restore в пустые volumes не изменяет рабочую базу.
3. **UI:** независимые от AI регистрация и ручные заметки, общий Crepe/CodeMirror, сохранение/переименование/экспорт. Приёмка: Markdown round-trip с формулами/таблицей/image/code, быстрая правка перед сохранением не теряется, ввод сохраняется при ошибке и конфликте. Лишних demo/URL/mock элементов нет.
4. **Подключения:** по делегированному выбору пользователя официальный Codex device flow для удалённого сервера, Claude через свой Anthropic API key. Приёмка: UUID-профиль, encrypted key, отсутствие CLI tokens в UI/Git/logs/localStorage, отключение/отмена/reauth. Старые host/учебные credentials новым людям не копируются.
5. **Обработка:** non-root Landlock per-job/per-user, отдельная media без egress и CLI profiles, fixed no-tools CLI argv, квоты/ресурсные лимиты. Приёмка: настоящий Whisper+PDF в новой изоляции, CLI/device-flow, запрет чтения соседнего профиля/secret; полный новый AI-запрос только после подтверждения своего аккаунта. Claude без ключа не объявлять проверенным. CPU fallback, host runtime не менять.
6. **Публикация:** production overlay/Caddy/SMTP TLS, strict config, support contact, protected secret volume, резервные копии. Приёмка: production отказывает без HTTPS/SMTP/emailverification/secret; изолированный HTTPS+STARTTLS тест с Secure cookie и ручной Note. Реальный DNS/ACME/доставку внешних писем проверять после появления домена и SMTP; не объявлять сайт опубликованным заранее.
7. **Финальная проверка:** unit/API/browser,1440/768/390 реальные screenshots и визуальный просмотр, build/audit/diff; запуск актуальной версии на localhost5180, сверка PRD/DESIGN/README. Без нового мусора submission/экспериментов в Git, без пуша и внешней публикации автоматически.

Границы: без произвольных URL/yt-dlp, OCR, PPTX, realtime, SSO, графа, вложенных папок, всего vault и публичного Quartz-export. Новых самостоятельных редакторов/Markdown-движков нет. Существующие konspekt, Obsidian, hse-notes, `.bashrc` и host CLI не меняются; localStorage/volumes не очищаются.

Приоритет — завершённый сценарий и честные подтверждённые результаты. Автоматический mock в LV_ENV=test проверяет очередь, не настоящую генерацию. Наличие кнопки/адаптера не равно проверенной внешней интеграции.
