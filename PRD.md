# LectureVault — PRD

Версия 4.3, 22 ноября 2026. Исходный scope ИДЗ согласован10ноября; переход от локального демо к настоящему сервису разрешён пользователем17ноября. Текущий документ описывает реализуемый продукт; исторический план сохранён в docs/plan-2026-11-10.md.

## Назначение

Личная и совместная библиотека технических Markdown-заметок. Пользователь может писать сам или получать черновик конспекта из видео и PDF через своё подключение AI. Чтение, организация и редактирование — основной рабочий сценарий; подключение AI необязательно.

## Обязательные сценарии

1. Email/password → письмо подтверждения → вход → пустая библиотека. При регистрации библиотека пуста. Восстановление доступа по email, смена пароля, отзыв сессий и удаление аккаунта.
2. Библиотека собственных и доступных по приглашению категорий → нужная категория или подкатегория → «Добавить заметку → Создать заметку» → сохранённая пустая Note → общий Milkdown Crepe → сохранение/переименование → Quartz-ридер → экспорт Markdown. Без видео, job и AI-профиля.
3. В настройках пользователь подключает Codex или свой OpenAI-совместимый API. Модели загружаются из каталога текущего провайдера. Уровень рассуждения выбирается, когда он заявлен в каталоге. Для Anthropic также доступен CLI.
4. «Добавить заметку → Сгенерировать конспект» принимает видео и PDF, в том числе перетаскиванием. Пользователь выбирает формат и модель, наблюдает очередь и процент распознавания, затем открывает Markdown с изображениями из презентации. Полный PDF доступен участникам категории в ридере.
5. Общая категория → owner добавляет подтверждённого пользователя по email → viewer читает/экспортирует или editor создаёт/редактирует → владелец меняет/отзывает роль. Каждая операция проверяется сервером, включая прямые запросы к источнику/вложению/export.
6. Одновременные правки: revision409 оставляет локальный черновик, его можно скачать и явно заменить актуальной версией. Realtime не нужен.

## Модель и хранение

User(UUID,email,password hash,verified); Session; корневая категория (исторический идентификатор Course); вложенные категории; Membership(owner/editor/viewer); Note(course,title,Markdown,revision,origin,необязательныйjob); Asset; GenerationJob; одноразовые auth links; encrypted mail outbox. SQLite WAL и Docker volumes. Markdown канонический; чтение не пересериализует его.

Корневая категория содержит заметки и подкатегории. Пустые подкатегории сохраняются самостоятельно. Ручные и сгенерированные заметки помещаются в выбранную ветку. Нет различия модели ручного и сгенерированного документа; общий Crepe и CodeMirror. Note можно создать с пустым телом, открыть из дерева, изменить, переименовать, удалить и экспортировать. Владелец задаёт значок и название категории на любом уровне. Команда «Объединить с родителем» переносит содержимое подкатегории на уровень выше. Изменение дерева сохраняет Markdown, ссылки на заметки и назначение активных заданий. Владелец удаляет корневую категорию; удаление аккаунта требует пароль и удаляет его категории, не чужие.

Состояния очереди: queued/acquiring/transcribing/preparing/generating/ready/failed/cancelled. Один worker, несколько сохраняемых заданий; отмена ожидающего и повтор failed только отправителем. Прерванная попытка после рестарта — failed/INTERRUPTED; ready не дублируется. После удаления результата в очереди нет фиктивного «Открыть».

Браузер хранит только черновики и UI-настройки отдельно по UUID. Старый localStorage импортируется явно, идемпотентно и без очистки оригинала. Сессии HttpOnly cookies, CLI access/refresh tokens не попадают в браузер.

## UX

Утверждён **Studio + Quartz Editorial**: rail44px, дерево236px, документ, полезный инспектор244px; Inter UI и Source Serif4 статья. Используются четыре оригинальных референса пользователя. Плоские списки, компактные состояния, настоящее оглавление, поиск по названию, keyboard focus/Escape/Ctrl+K. Нет hero, рекламных слоганов, декоративных карточек и dashboard-графиков. Настройки разделены на профиль/подключения/безопасность; поля подключения появляются только по действию пользователя. Удаление — вторичное действие в меню. Форма создания и готовый редактор следуют тем же токенам/плотности. Детали — DESIGN.md.

Два сценария «Добавить заметку» и возврат после создания первой категории. Формы сохраняют настройки, ошибки находятся рядом с полями. Видео/PDF после обновления нужно выбрать повторно; это явно обозначено. Без AI-подключения отправка не начинает upload. На1440×1000,768px,390×844 проверяются библиотека, форма, очередь, ридер, регистрация и настройки; широкие таблицы/код/формулы имеют собственную прокрутку.

## Архитектура

React/TypeScript/Vite, оригинальные Quartz5 ContentBody/TOC через Preact и upstream SCSS, готовые remark/rehype/KaTeX. Milkdown Crepe и CodeMirror без собственного редактора. FastAPI/SQLite, отдельные worker/mailer/media/providers, Docker Compose. Media без внешней сети и AI-профилей. Каждый CLI-процесс видит собственный UUID-профиль через Linux Landlock; broker не имеет Docker socket или host home. Обработка non-root, статические argv, без shell=True.

## Лимиты и границы

Видео512МБ/3ч, PDF50МБ/500стр; PNG/JPEG/WebP10МБ, SVG upload запрещён. Транскрипт140000символов, для длинных PDF в модель передаются выдержки до 40000 символов. Assets1ГБ на владельца категории/10ГБ экземпляра,100 корневых категорий/5000заметок/25МБ Markdown на владельца;10активных/30новыхзаданий в сутки на отправителя. Изображения/источники выдаются через ACL API. Exact Origin/Host, CSRF header, rate limits, Argon2id, HTTPS/Secure cookie для production, SMTP TLS, encrypted secrets/outbox.

Не входят: произвольные URL/yt-dlp (SSRF-путь закрыт), OCR, PPTX, CUDA без runtime, realtime, SSO, граф, вложенные папки, весь Obsidian vault, public/unlisted документы и Quartz publishing. Ничего не меняет konspekt/hse-notes/Obsidian/host CLI. Нет автопубликации и Git push. Mock существует только в изолированных LV_ENV=test проверках, не в рабочем сервисе.

## Приёмка и статус публикации

- Чистый Compose без seeds; реальная регистрация и email verification/recovery, правильные сессии и отсутствие доступа к чужим ресурсам.
- Ручной Markdown полностью работает без AI: create/edit/rename/save/reload/export/delete, пустой документ и rich round-trip.
- Роли и конфликт409 проверены API и браузером; очередь cancel/retry/navigation/reload — отдельными тестами без платных вызовов.
- После личного входа пользователя в новый Codex-профиль проверен настоящий короткий видеофрагмент+PDF→Whisper→Codex (`gpt-6-luna`,low), non-root/Landlock, без mock. Использованы временные DB/job-файлы: рабочая библиотека не наполнялась тестовыми данными. Старые credentials не передавались. Для OpenAI API проверены передача параметров, обработка ошибок и сохранение результата на тестовом HTTP-ответе. Платные вызовы Claude и OpenAI по ключу остаются за пределами этой приёмки.
- Production overlay с Caddy/HTTPS и TLS SMTP проверяется локальными тестовыми сертификатами. Настоящие домен, DNS, публичный сертификат и доставка внешних писем пока не настроены: у владельца ещё нет домена/SMTP. Подготовка к публикации не равна опубликованному сервису.
- Backups/restore проверяются в пустом окружении; секреты/профили не входят в backup, пользователи восстанавливают пароли и подключают AI заново.

Критерии ИДЗ: законченный сценарий, PRD/DESIGN/референсы, авторизация/хранение, воспроизводимый запуск и честная демонстрация. Реальный pipeline, PDF, права, очередь и конфликты — дополнительная сложность; обещать оценку10/10 нельзя.
