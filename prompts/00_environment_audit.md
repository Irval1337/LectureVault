# Codex prompt 00 — только аудит среды

Проверь текущую локальную среду для проекта LectureVault. Пока ничего не устанавливай, не создавай, не меняй и не запускай долгую обработку видео.

1. Назови точный рабочий каталог, список файлов и версию Node.js/npm, Python, доступность React/Vite, FastAPI, SQLite, `yt-dlp`, ffmpeg, whisper.cpp, Claude CLI, Codex CLI.
2. Прочитай `PRD.md`, `DESIGN.md`, `USER_FLOW.md`, `CODEX_PLAN.md`. Кратко перечисли границы первой версии.
3. Read-only осмотри описанный в PRD существующий пайплайн: реальное расположение функции `konspekt`, `summarize`, `kq`, очереди, обработку PDF/PPTX, запись Markdown и вложений. **Не показывай секреты** и не копируй пользовательские записи в ответ. Если исходные пути недоступны, честно скажи, что отсутствует и какие альтернативы возможны.
4. Выясни, можно ли корректно вызывать существующие функции из non-interactive subprocess; `konspekt` — Bash-функция, не рассчитывай, что обычный `subprocess.run(["konspekt", ...])` заработает.
5. Предложи минимальную архитектуру адаптера без изменений исходных скриптов и с безопасной обработкой параметров/имен файлов; оцени, что можно реально запустить на этой машине.

Выход: отчет в ответе с найденными блокерами, зависимостями и рекомендацией следующего шага. Файлы пока не трогай. Никаких дополнительных agent skills.
