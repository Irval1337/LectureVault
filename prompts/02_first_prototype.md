# 02 — Промежуточный прототип (после одобрения плана)

Прочитай docs/plan-2026-11-10.md, PRD.md, DESIGN.md, USER_FLOW.md. Не меняй ранее согласованный scope.

Реализуй локально React/Vite+TypeScript, Tailwind и shadcn/ui. Собери в стиле Quartz трехколоночный интерфейс: слева `WorkspaceExplorer` (пространства/курсы/документы), в центре основной экран, справа TOC/контекст. Используй референсы quartz-user.png, obsidian-user.png, notion-user.png и editor-user.png (последний для следующей фазы).

Основной демо-flow: пустая библиотека → создать курс → глобальная или контекстная кнопка `Новый конспект` → URL/видеофайл + необязательная презентация и инструкции + режим Лекция/Семинар → mock задача в очереди с осмысленными стадиями → готовый Markdown из fixtures/demo-note.md → Quartz-style reader с заголовками/TOC/формулами. Mock обозначить явно. Не запускать тяжелый CLI на этом этапе.

Визуальное редактирование допустимо подключить сразу через **готовый Milkdown Crepe**, если не мешает промежуточному дедлайну. Не писать свой редактор на contenteditable. Не начинать полноценную реализацию Quartz fork/public export.

После выполнения: запусти приложение, укажи URL, проверь сценарий вручную, перечисли изменения, отдельно пометь mock. Потребуется видео до 60 секунд, PRD, DESIGN, screenshot референса и короткий комментарий.

## Утверждённое уточнение

Сначала закончить UX. Не более 60 минут на интеграцию оригинальных компонентов Quartz 5; допускается частичное переиспользование стабильных компонентов и fallback react-markdown/remark/rehype + стили Quartz. Данные курсов, документов и mock-заданий хранить в localStorage; поддержать refresh. Все видимые действия должны работать, без фиктивных кнопок редактора/публикации. Не подключать настоящий backend/Whisper/Claude. Подготовить реальные скриншоты 1440/390 и сценарий видео, README запуска и сверить PRD/DESIGN с фактом. Пользователь разрешил самостоятельное завершение этого этапа и визуальные исправления в рамках согласованного дизайна без повторного подтверждения каждого шага.
