# 03 — UI/UX refinement

Перед правками изучи PRD.md, DESIGN.md и USER_FLOW.md. Открой все четыре **пользовательских** скриншота:
- docs/reference/quartz-user.png — главная компоновка / статья / Explorer / TOC;
- docs/reference/obsidian-user.png — навигация и организация по папкам;
- docs/reference/notion-user.png — личные и общие пространства;
- docs/reference/editor-user.png — панель и визуальное редактирование.

Сначала опиши, что ты реально видишь на скриншотах, и сравни с текущим UI в формате: элемент → расхождение → исправление. Не фантазируй о невидимых деталях. Ориентируйся в первую очередь на Quartz 3-col и наши согласованные решения (в PRD версия 2.0). Предпочтительна темная тема сайта, ридер может переключаться в светлую.

Обязательные UX-проверки: нет пустых бессмысленных карточек; создать конспект можно глобально или из курса; дерево, breadcrumbs, TOC; clear mock/real status; светлая/темная тема; аккуратный display long Markdown, LaTeX, image and code; состояния загрузки и ошибки; адаптивность 1440/390.

**Пока ничего не меняй**: выдай список конкретных правок и согласуй их. После одобрения измени UI и DESIGN.md синхронно.
