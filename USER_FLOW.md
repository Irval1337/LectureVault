# LectureVault — пользовательские сценарии

Актуально17ноября2026. Утверждённая визуальная система — Studio + Quartz Editorial, подробности в DESIGN.md.

## Регистрация и вход

Email, имя, пароль15–128символов и повтор → письмо подтверждения → явное подтверждение → пустая библиотека. Повторная отправка не раскрывает существование чужого email. В локальном Compose письмо находится в Mailpit8026, в production доставляется собственным SMTP. Пароль забыт → письмо со ссылкой30мин → новый пароль → обычный вход; прежние сессии отзываются. Ссылки единоразовые; токен во fragment URL удаляется из строки адреса.

Внизу проводника имя пользователя → Настройки: профиль, подключения, смена пароля, выход, завершение всех сессий, удаление своего аккаунта с паролем/подтверждением. Privacy доступна и до входа. Подключение AI не участвует в регистрации.

## Навигация и курсы

Rail: библиотека / Новый / очередь. Проводник: личное/общее пространство, поиск по названиям, дерево курс→Note. Ctrl/Cmd+K фокусирует поиск, активная заметка выделена, длинные имена имеют title. На мобильном — drawer с focus trap/Escape и закрытием после перехода. Breadcrumb ведёт обратно к курсу.

Новая библиотека пуста. Создание курса не добавляет заметок или участников. В общем курсе «Доступ» позволяет владельцу добавить уже зарегистрированного и подтвердившего email пользователя с viewer/editor, сменить роль и отозвать доступ. Viewer читает/скачивает, editor создаёт/редактирует/удаляет заметки, owner управляет курсом/участниками. Личный курс видит только владелец. Сервер проверяет также прямые API/file/export запросы.

## Ручная заметка

«Новый → Создать заметку» → выбрать курс или создать первый → пустая Note «Без названия» уже на сервере и в дереве → общий Milkdown Crepe. Переименовать/написать → сохранить (Ctrl/Cmd+S) → чтение → reload → экспорт `.md`. Допустим пустой Markdown. Вкладка Markdown — готовый CodeMirror; оба режима сохраняют формулы, таблицы, изображения и код. Источника/job/mock-пометки у ручного документа нет.

При revision409 введённый текст не перезаписывается. Можно скачать черновик и явно загрузить актуальную версию. При обычной ошибке сохранения текст остаётся в браузере. Удаление заметки требует подтверждения; удаление курса owner удаляет его документы/материалы и блокируется активной обработкой.

## Подключения и генерация

Настройки → Codex → Подключить → официальная страница OpenAI и одноразовый device-код → подтвердить своим аккаунтом → статус обновляется автоматически. Помощь по разрешению device login скрыта до запроса. Никакого loopback callback/SSH-туннеля на публичном сервере. Отмена входа и отключение работают с собственным профилем.

Альтернатива — свой Anthropic API key для Claude, оплачиваемый отдельно от подписки Claude.ai. Ввод только в password-поле; после сохранения ключ не возвращается в UI. Отображение сохранённого ключа не означает успешную платную генерацию. Важные изменения подключения после15мин требуют повторного ввода пароля LectureVault.

«Новый → Сгенерировать конспект» → локальное видео → необязательный PDF → название/курс/пресет/объём/язык/инструкции/модель/effort → создать. Без AI показывается ссылка на настройки, отправка блокируется до upload. Ошибки конкретны и рядом с полем. Настройки переживают переходы/reload; файлы после reload выбираются повторно. Создание курса возвращает к заполненной форме.

## Очередь и чтение

queued → acquiring → transcribing → preparing → generating → ready/failed. Можно уйти/вернуться/reload: работа продолжается сервером. Cancel только своего queued; retry только своего failed. После аварии worker прерванная задача становится failed/INTERRUPTED с повтором; готовые Note не дублируются. Ошибка real не превращается в mock. Произвольные URL выключены.

Ready → Quartz-ридер → настоящее оглавление/формулы/таблицы/код/изображения → общий редактор → сохранение/скачивание. Desktop справа только полезный контекст. На мобильном оглавление раскрывается над статьёй и закрывается после выбора; широкие блоки прокручиваются внутри, а не всем viewport. Если результат удалён, очередь не предлагает открыть несуществующую Note.

## Данные и проверка

Старый `lecturevault.library.v1` импортируется только явной кнопкой, идемпотентно и в личные курсы; оригинальный localStorage и старые jobs не удаляются. Никаких автоматических демоданных. Нажатие удаления аккаунта удаляет собственные курсы, доступы, профиль AI и browser-настройки этого UUID; не очищает чужие записи браузера или личные инструменты.

Приёмка: регистрации/SMTP/восстановление, ручной rich Markdown/save/reload/export, настоящие роли/отзыв/конфликт, несколько jobs/cancel/retry, поиск/мобильное оглавление/Escape, импорт без потери. Chromium1440×1000,768px,390×844. Test-only очередь не является доказательством платного AI-вызова. Публичный DNS/SMTP требуют настройки владельцем.
