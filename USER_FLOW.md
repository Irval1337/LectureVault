# LectureVault — пользовательские сценарии

Актуально: 17 ноября 2026. Studio + Quartz Editorial; итоговый scope 19 ноября.

## Вход и навигация

Открыть localhost → выбрать Алексей/Мария → личная библиотека. Rail переключает библиотеку, «Новый» и очередь. Проводник содержит выбор личного/общего пространства, поиск, курсы и заметки. Ctrl/Cmd+K открывает поиск; Escape закрывает диалоги; на mobile проводник в drawer. Прямая ссылка на Note раскрывает её курс. Breadcrumbs и «К курсу» возвращают к списку.

Имя пользователя внизу проводника → «Подключения»: вход/статус Codex и Claude, выход из LectureVault. При создании реального конспекта также доступно «Войти в выбранного провайдера». Codex открывает официальный браузерный OAuth, без device-кода и включения device auth в настройках. После подтверждения статус обновляется автоматически. CLI credentials остаются в отдельном серверном профиле пользователя. Модель и effort выбираются в форме генерации, а не в окне входа.

Личный курс доступен только владельцу. Общий курс изначально доступен обоим демопользователям; владелец в «Доступ» меняет editor/viewer/нет доступа. Права применяются сервером и к прямому API-запросу. Mock login без пароля — только localhost.

## Создание

**«Новый» → «Создать заметку»**: выбрать доступный для записи курс → сохранить Note «Без названия» с Markdown `''` → открыть общий Milkdown Crepe. Источник и задание не создаются. Можно сохранить пустое тело, написать текст, изменить название, открыть из дерева и экспортировать Markdown. У ручной заметки нет фиктивного источника или стадий.

**«Новый» → «Сгенерировать конспект»**: выбрать курс → источник → настройки → создать job. Контекстный `+` курса предвыбирает его. Если курсов нет, сначала создать первый и продолжить выбранный сценарий. Создание курса из заполненной формы сохраняет остальные поля.

Реальный путь: видео MP4/MOV/MKV/WebM до 512 МБ → optional PDF до 50 МБ → название, курс, Лекция/Семинар, объём, язык и инструкции → Codex/Claude, модель и effort → отправить. Ошибки рядом с полями сохраняют ввод. После refresh настройки восстанавливаются, файлы нужно выбрать снова; форма сообщает об этом. Реальный URL недоступен. PDF требует текстового слоя и не более 100 страниц.

Демо-путь: выбрать «Демо без анализа» → файл или HTTP(S)-ссылка → параметры → mock-job. По URL сетевых запросов нет, файлы сохраняются локально, но не анализируются. Демо-результат явно отмечен. `/demo` — отдельные read-only примеры, без добавления их в пользовательские данные.

## Очередь и результат

queued → acquiring → transcribing → preparing → generating → ready либо failed. Задания выполняются последовательно на сервере; выход на другой экран, refresh и закрытие браузера не останавливают worker. Можно отменить ожидающее своё задание и повторить своё failed. Несколько заданий сохраняют порядок. После рестарта worker прерванная попытка становится failed/INTERRUPTED с возможностью повтора; готовые Note не дублируются. Ошибка реального задания не заменяется mock.

Ready → «Открыть» → Quartz ContentBody и настоящее оглавление с переходами. Таблицы, код и формулы имеют собственный горизонтальный scroll; страница не переполняет mobile viewport. Справа только оглавление и доступные сведения об источнике, на mobile они в содержимом. Защищённые видео/PDF можно скачать из источников. Сохранённый Markdown скачивается без пересериализации.

## Редактирование и конфликт

Owner/editor → «Редактировать» → тот же готовый Milkdown Crepe для ручной и сгенерированной Note. «Markdown» открывает готовый CodeMirror; переключение сохраняет текущий текст. Название, сохранение и Ctrl/Cmd+S общие. Сохранение повышает revision, дерево и имя экспорта обновляются, ссылка остаётся прежней.

Несохранённый черновик привязан к пользователю/Note/браузеру. 409 при чужой правке оставляет его нетронутым: скачать черновик, затем явно подтвердить загрузку актуальной версии. Viewer читает и экспортирует, но не редактирует и не создаёт задания/вложения.

## Перенос промежуточной библиотеки

Если найден `lecturevault.library.v1`, появляется явная кнопка импорта. Курсы/Markdown копируются в личную серверную библиотеку пользователя; исходный localStorage не удаляется. Повтор того же импорта не дублирует документы. Старые mock-jobs остаются в исходной копии; в промежуточной версии медиа не сохранялись.

## Приёмка

Проверить оба пути создания, пустое тело, переименование/экспорт/reload, круг Crepe ↔ CodeMirror с формулами/таблицами/кодом/изображением, несколько jobs/cancel/retry, реальные права двух пользователей и conflict. Снимки библиотеки, формы, очереди и ридера: 1440×1000, 768px, 390×844. Реальную Whisper → Codex цепочку проверять отдельно; автоматическая демо-приёмка не считается доказательством real pipeline.
